## Key Features Demonstrated

- Natural, human-like voice interactions
- Real-time speech-to-text transcription
- Intent classification and parameter extraction
- Appointment scheduling, rescheduling, and cancellation
- Context-aware responses
- Empathetic tone and prosody
- Seamless integration with backend systems

## Viewing the Demos

The demo videos are located in the `demo/` directory at the root of the repository. These recordings showcase the platform that won the grand prize at SpinSci AI Hackathon 2025.

## Technical Implementation

The demos showcase the integration of:
- Twilio for telephony
- Deepgram Nova for speech-to-text
- GPT-3.5/Ollama for language understanding
- ElevenLabs/OpenAI TTS for voice synthesis
- Pipecat for orchestration

For more information on the technical architecture, see the main [README.md](../README.md).
